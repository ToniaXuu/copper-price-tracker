## 1. 项目定位与命名

### 1.1 命名

| 方案     | 名称                         | 说明                                                                 |
| ------ | -------------------------- | ------------------------------------------------------------------ |
| **推荐** | **`copper-price-tracker`** | 与 `fuel-price-tracker` 完全同构：`{商品}-price-tracker`。语义直白、可读性最好、SEO 友好 |
| 备选     | `cu-price-tracker`         | 更短，`CU` 是沪铜期货代码。缺点是圈外人看不懂                                          |
| 备选     | `copper-tracker`           | 更短，但丢了 `price`，与油价的命名节奏不一致                                         |

**采用 `copper-price-tracker`。** 理由：命名一致性本身就是资产——两个项目并排展示时，一眼就能看出是同一系列产品。

### 1.2 一句话定位

> 追踪沪铜期货 + 国内现货电解铜价格，每日推送涨跌与成本影响，为电力设备/线缆采购决策提供价格锚点。

### 1.3 与油价项目的关系

不是"复制粘贴换个数字"，而是**同一套架构的第二条产品线**。差异在于：

- 油价是**行政调价**（10 个工作日一轮，发改委定），铜价是**连续交易**（每个交易日都有价）
- 油价数据源以**政府公告**为主，铜价数据源以**行情接口**为主
- 油价关注"什么时候去加油"，铜价关注"什么时候下单采购"

### 3.2 数据源分级策略（多源降级，与油价项目一致）

```
主指标 · 沪铜期货
  ├─ L1 新浪 InnerFuturesNewService.getDailyKLine ── 历史序列（首选，20 年连续）
  ├─ L2 上期所 kx{date}.dat ─────────────────────── 官方结算价（权威校验）
  └─ L3 新浪 hq.sinajs.cn nf_CU0 ─────────────────── 实时盘中兜底

副指标 · 现货电解铜
  └─ 生意社 plist-1-61（两步 cookie 握手）

参考指标 · 国际盘
  └─ 新浪 hf_CAD（LME 铜 3 月）
```

### 3.3 ⚠️ 三个必须记住的坑（实测踩出）

**坑 1：新浪 `CU0` 是僵尸代码，必须用 `nf_CU0`**

```
hq.sinajs.cn/list=CU0     → "沪铜连续, ..., 2024-07-17"   ❌ 停在 2024 年的死数据
hq.sinajs.cn/list=nf_CU0  → "铜连续, ..., 2026-09-30"      ✅ 正确
```

两者都能返回 200 和合法格式，**数值却相差两年**。用错会拿到 78,730 元/吨（2024 年价），而行情已到 109,640。这是最危险的一个坑——它不会报错。

**坑 2：SHFE 的 `SETTLEMENTPRICE` 和 `CLOSEPRICE` 在盘中为空字符串**

实测（2026-09-30 09:37，盘中）：

```json
{"PRODUCTID":"cu_f","DELIVERYMONTH":"2611","OPENPRICE":109280,
 "HIGHESTPRICE":109790,"LOWESTPRICE":109270,
 "SETTLEMENTPRICE":"","CLOSEPRICE":""}   ← 空！
```

→ **定时任务必须放在 15:00 收盘结算之后**，否则拿到的是不完整数据。

**坑 3：现货报价是 JS 异步加载的，别指望直接抓 HTML**

`ccmn.cn` 首页虽在搜索引擎快照里能看到「1#铜 109000-109040」表格，但**原始 HTML 里 `1#铜` 一次都不出现**（实测 `h.find('1#铜') == -1`）。只有 2 个 `<table>`、0 个 ajax/json 关键词——数据完全是运行时注入的。

**生意社的绕过方案（实测通过）：**

```python
# 第 1 步：请求 → 拿到 JS 挑战页（仅 660 字节）
r1 = requests.get("https://www.100ppi.com/mprice/plist-1-61-1.html", headers=UA)
token = re.search(r'"([0-9a-f]{32})"', r1.text).group(1)   # HW_CHECK 挑战值

# 第 2 步：带上 cookie 重放 → 拿到 423 KB 真页面
r2 = requests.get("https://www.100ppi.com/mprice/plist-1-61-1.html",
                  headers=UA, cookies={"HW_CHECK": token})
# → 解析出：1#电解铜 / 标准阴极铜Cu-CATH-2 / 上海华通 / 110990元/吨 / 2026-09-29
```

注意：挑战 token 有效期内可复用，但**跨运行可能轮换**，必须每次重新握手。

### 3.4 现货历史序列的现实约束

- **期货历史**：新浪一次请求拿到 2005 年至今 5289 条 → 开箱即用
- **现货历史**：生意社页面只给最近若干交易日的多供应商报价 → **没有免费的长历史**

→ **设计结论**：`data.json` 里期货序列回填 20 年，现货序列**从上线的第一天起自行累积**。页面标注现货为「自建序列，自 YYYY-MM-DD 起」。不伪造历史。

### 6.1 口径定义（必须在文档里写死，否则日后必吵）

| 指标      | 口径                                 | 理由                     |
| ------- | ---------------------------------- | ---------------------- |
| **主指标** | 沪铜**连续合约（CU0）结算价**                 | 历史连续、无需人工处理换月、有官方结算价背书 |
| 现货      | 生意社「1#电解铜 / 标准阴极铜 Cu-CATH-2」多供应商均价 | 国内现货最通用口径              |
| 基差      | 现货均价 − 期货结算价                       | 现货升水/贴水，供需松紧信号         |
| 沪伦比     | 沪铜(元/吨) ÷ LME(美元/吨)                | 进口盈亏与内外盘套利参考           |

> ⚠️ **为什么主指标选连续合约而不是主力合约**：主力合约每月换月，历史序列会出现口径断裂（昨天记 2611，今天记 2612），补数极难对齐。连续合约是交易所标准拼接口径，20 年一条线。

## 7. 与油价项目的差异点（不能照搬的地方）

| 维度    | 油价              | 铜价               | 处理                             |
| ----- | --------------- | ---------------- | ------------------------------ |
| 更新频率  | 10 个工作日一轮       | 每交易日             | 油价"轮次"概念 → 铜价改为"交易日"           |
| 价格方向  | 只有涨/跌/搁浅        | 连续变动             | `type` 字段由离散枚举改为连续 `change` 数值 |
| 历史数据  | 靠公告逐轮累积         | 一次 API 拿到 20 年   | 首次运行需**回填迁移**脚本                |
| 换算逻辑  | 吨价 ÷ 1250 = 元/升 | 吨价 ÷ 1000 = 元/公斤 | 更简单，但需保留 3 位小数精度               |
| 时间敏感度 | 调价 24 时生效，需及时   | 收盘后出数即可          | 推送时点从 09:00 改 08:30            |
| 节假日   | 不受影响            | 春节/国庆长休市         | 需交易日历判断，避免记录空值                 |

## 9. 风险清单

| 风险                     | 等级    | 影响         | 对策                                                       |
| ---------------------- | ----- | ---------- | -------------------------------------------------------- |
| 生意社改版 / 加强反爬           | **高** | 现货价断供      | ①现货仅作副指标，断了不影响主指标；②健康告警顶进推送；③备选长江有色 AJAX 逆向或 headless 渲染 |
| 用错 `CU0` 拿到 2024 年僵尸数据 | **高** | 整整偏两年、且不报错 | 硬编码 `nf_CU0`；加"日期必须 ≥ 今天-7 天"的断言                         |
